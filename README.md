# Peluna

Offline, score-based diary app. Which
- Local only.
- No BS cloud.
- No BS ads.
- You own everything.
- Cross Platform (currently only support Android, because i am too lazy)

> [!WARNING]
> This app is vibe coded. lol

## Installing

Download the APK from the [latest release](https://github.com/hingjasontech/peluna/releases/latest).
Android may warn that the app is from an unknown developer; that is expected
for a sideloaded app. You can check for updates from Settings; Peluna opens
the release page in your browser instead of installing APKs itself.

> [!NOTE]
> The Android package was renamed from `com.example.peluna` to
> `com.voidcord.peluna`. The new APK installs as a separate app. Export your
> diaries from the old app, download the new APK in your browser (not through
> the old app's update button), install it, then import the backup.
